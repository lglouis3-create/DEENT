# Change log

Newest first. The build embeds this file: the Topics page shows what is new
since the reader's last visit, and Settings shows all of it. One short line per
bullet, in the reader's terms — what they can now do or what is now right, not
which file changed. `style_check.js` fails on a bullet longer than 120
characters.

Every update adds its bullets here in the same commit that makes the change.
